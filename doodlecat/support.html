Common questions

Does my child need an account?

No. There is no sign-in. Drawings and progress stay on this device.

How do I open the parent area?

Tap the parent button and answer the multiplication question on screen.

How do I print coloring pages?

In the parent area, open Printable packs and choose Print or Save. The iOS share sheet opens with a PDF.

Reminders do not appear.

Check Settings > Notifications > DoodleCat and allow notifications, then set the reminder again in the parent area.

I got a new phone. Where are the drawings?

Before switching, open the parent area > Backup & recovery and export a backup file (save it to Files or iCloud Drive). On the new phone, install DoodleCat and import that file from the same screen.

Is there anything to buy?

Not in version 1.0. There are no ads and no in-app purchases.
